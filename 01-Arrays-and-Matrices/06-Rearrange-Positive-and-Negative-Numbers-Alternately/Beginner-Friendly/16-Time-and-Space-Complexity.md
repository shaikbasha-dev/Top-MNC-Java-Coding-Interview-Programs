# Time and Space Complexity — Rearrange Positive and Negative Numbers Alternately

## Time Complexity

**Time Complexity: `O(n)`**

### Why?

The beginner version separates positive and negative values into additional arrays.

## Space Complexity

**Space Complexity: `O(n)`**

### Why?

The extra memory used by the algorithm is constant unless the algorithm explicitly creates an additional array.

## Interview Point

Always explain not only the Big-O value but also **why** the number of operations grows in that way.
