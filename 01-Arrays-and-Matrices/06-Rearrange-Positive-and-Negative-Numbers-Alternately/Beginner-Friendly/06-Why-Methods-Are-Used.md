# Why Methods Are Used — Rearrange Positive and Negative Numbers Alternately

## main()

### What the Method Does
It gives the Java runtime the starting point of the application.

### Why It Is Used Here
It gives the Java runtime the starting point of the application.

### Where It Is Used
It is used directly in the executable Java program.

### What Happens If We Do Not Use It
The standard Java launcher would not have the normal application entry point.

### Key Point
Use the method because it matches the required role of the program: starting execution or displaying the result.
