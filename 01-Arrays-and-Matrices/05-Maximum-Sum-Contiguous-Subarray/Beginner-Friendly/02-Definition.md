# Definition — Maximum Sum Contiguous Subarray

## Technical Definition

Find the contiguous part of an integer array having the largest possible sum.

## Simple Definition

In simple words, this problem asks us to look at the given data and find or produce the result required by a specific rule.

## Beginner-Friendly Explanation

Imagine solving the problem manually with a pen and paper. First identify the input, then follow the rule one step at a time. The Java program performs the same process systematically.

## Important Terms

- **Input:** The values given to the program.
- **Output:** The result produced by the program.
- **Index:** The position of an element in an array.
- **Iteration:** One execution of a loop.
- **Condition:** A rule that determines whether a particular block of code should execute.
- **Result:** The value or arrangement requested by the problem.
