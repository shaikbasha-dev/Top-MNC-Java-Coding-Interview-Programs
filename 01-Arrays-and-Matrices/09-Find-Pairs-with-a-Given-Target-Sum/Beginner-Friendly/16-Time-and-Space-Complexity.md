# Time and Space Complexity — Find Pairs with a Given Target Sum

## Time Complexity

**Time Complexity: `O(n²)`**

### Why?

Every pair is checked in the beginner version.

## Space Complexity

**Space Complexity: `O(1)`**

### Why?

The extra memory used by the algorithm is constant unless the algorithm explicitly creates an additional array.

## Interview Point

Always explain not only the Big-O value but also **why** the number of operations grows in that way.
