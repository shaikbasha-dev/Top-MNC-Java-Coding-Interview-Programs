# Time and Space Complexity — Maximum Profit from Stock Prices

## Time Complexity

**Time Complexity: `O(n)`**

### Why?

Each price is checked once and only a fixed number of variables is maintained.

## Space Complexity

**Space Complexity: `O(1)`**

### Why?

The extra memory used by the algorithm is constant unless the algorithm explicitly creates an additional array.

## Interview Point

Always explain not only the Big-O value but also **why** the number of operations grows in that way.
