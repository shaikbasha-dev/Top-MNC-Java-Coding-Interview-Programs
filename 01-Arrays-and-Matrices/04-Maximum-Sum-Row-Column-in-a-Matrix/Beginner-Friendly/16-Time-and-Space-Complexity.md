# Time and Space Complexity — Maximum Sum Row/Column in a Matrix

## Time Complexity

**Time Complexity: `O(r × c)`**

### Why?

Rows and columns are traversed to calculate their sums.

## Space Complexity

**Space Complexity: `O(1)`**

### Why?

The extra memory used by the algorithm is constant unless the algorithm explicitly creates an additional array.

## Interview Point

Always explain not only the Big-O value but also **why** the number of operations grows in that way.
