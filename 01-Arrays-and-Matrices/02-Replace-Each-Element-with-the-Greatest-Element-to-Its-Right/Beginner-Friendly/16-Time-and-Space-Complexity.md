# Time and Space Complexity — Replace Each Element with the Greatest Element to Its Right

## Time Complexity

**Time Complexity: `O(n²)`**

### Why?

The beginner version checks the elements to the right for every element.

## Space Complexity

**Space Complexity: `O(1)`**

### Why?

The extra memory used by the algorithm is constant unless the algorithm explicitly creates an additional array.

## Interview Point

Always explain not only the Big-O value but also **why** the number of operations grows in that way.
