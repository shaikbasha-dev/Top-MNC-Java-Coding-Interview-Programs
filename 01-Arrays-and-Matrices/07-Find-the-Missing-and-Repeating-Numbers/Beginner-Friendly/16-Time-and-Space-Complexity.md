# Time and Space Complexity — Find the Missing and Repeating Numbers

## Time Complexity

**Time Complexity: `O(n)`**

### Why?

The frequency array stores counts for values from 1 through N.

## Space Complexity

**Space Complexity: `O(n)`**

### Why?

The extra memory used by the algorithm is constant unless the algorithm explicitly creates an additional array.

## Interview Point

Always explain not only the Big-O value but also **why** the number of operations grows in that way.
