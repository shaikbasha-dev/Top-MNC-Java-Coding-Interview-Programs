## Detailed Explanation

### Class

A class is the container that holds Java program code.

General example:

```java
class Student {
}
```

In this program, the class contains the complete executable code.

### main() method

The `main()` method is the starting point of a Java application.

General example:

```java
public static void main(String[] args) {
    System.out.println("Hello");
}
```

### Arrays

An array stores multiple values of the same type under one variable name.

General example:

```java
int[] numbers = {10, 20, 30};
```

The current program uses an array to store the input data.

### Frequency array

An array stores multiple values of the same type under one variable name.

General example:

```java
int[] numbers = {10, 20, 30};
```

The current program uses an array to store the input data.

### for loops

A loop repeats a group of statements until its condition is no longer satisfied.

General example:

```java
for (int i = 0; i < 3; i++) {
    System.out.println(i);
}
```

### if statement

An `if` statement makes a decision based on a condition.

General example:

```java
if (number > 0) {
    System.out.println("Positive");
}
```

### Variables

A variable is a named memory location used to store a value.

General example:

```java
int age = 25;
```

### Increment operator

Operators allow Java to perform calculations, comparisons, or assignments.

General example:

```java
int sum = first + second;
```

### System.out.println()

`System.out.print()` displays text without automatically moving to a new line.

General example:

```java
System.out.print("Hello");
```
