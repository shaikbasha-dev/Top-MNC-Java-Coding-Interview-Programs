# Time and Space Complexity — Left Rotate an Array by K Positions

## Time Complexity

**Time Complexity: `O(n)`**

### Why?

Every input element is copied once into the rotated array.

## Space Complexity

**Space Complexity: `O(n)`**

### Why?

The extra memory used by the algorithm is constant unless the algorithm explicitly creates an additional array.

## Interview Point

Always explain not only the Big-O value but also **why** the number of operations grows in that way.
