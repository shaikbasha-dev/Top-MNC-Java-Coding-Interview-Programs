# Method Definitions and Examples — Spiral Traversal of a Matrix

This file gives simple definitions and general examples for the callable methods used in the program.

## 1. main()

**Definition:** The `main()` method is the standard entry point of a Java application.

**General example:**

```java
public static void main(String[] args) {
    System.out.println("Hello Java");
}
```

The Java runtime starts the program from this method.

## 2. System.out.println()

**Definition:** `println()` prints a value and moves to the next line.

**General example:**

```java
System.out.println("Hello Java");
```

## 3. System.out.print()

**Definition:** `print()` prints a value without automatically moving to the next line.

**General example:**

```java
System.out.print("Hello ");
System.out.print("Java");
```

Only the methods actually present in the program should be considered relevant. Array `length` is a field, not a method.
