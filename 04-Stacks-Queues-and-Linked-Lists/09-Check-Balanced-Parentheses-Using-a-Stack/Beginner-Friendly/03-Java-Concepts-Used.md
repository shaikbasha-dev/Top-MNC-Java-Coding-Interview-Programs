# 03 — Java Concepts Used

## Concepts List

1. Stack
2. LIFO
3. Characters
4. Matching pairs
5. Conditional statements

## Expanded Explanation

### Stack

A LIFO data structure.

**General Example:**
```java
stack.push(10); stack.pop();
```

### LIFO

Last In, First Out.

**General Example:**
```java
20 enters last, so 20 leaves first.
```

### Characters

A String can be processed one character at a time.

**General Example:**
```java
char ch = expression.charAt(0);
```

### Matching pairs

Opening symbols must match their corresponding closing symbols.

**General Example:**
```java
( ) [ ] { }
```

### Conditional statements

Conditions select an operation based on the current value.

**General Example:**
```java
if (ch == '(') { }
```
