# 03 — Java Concepts Used

## Concepts List

1. Queue
2. Stack
3. FIFO
4. LIFO
5. Stack operations
6. Classes and objects

## Expanded Explanation

### Queue

A FIFO data structure.

**General Example:**
```java
queue.offer(10); queue.poll();
```

### Stack

A LIFO data structure.

**General Example:**
```java
stack.push(10); stack.pop();
```

### FIFO

First In, First Out.

**General Example:**
```java
10 enters before 20, so 10 leaves first.
```

### LIFO

Last In, First Out.

**General Example:**
```java
20 enters last, so 20 leaves first.
```

### Stack operations

Push, pop and peek are common stack operations.

**General Example:**
```java
stack.push(5);
```

### Classes and objects

A class defines a type and an object is an instance of it.

**General Example:**
```java
MyStack stack = new MyStack();
```
