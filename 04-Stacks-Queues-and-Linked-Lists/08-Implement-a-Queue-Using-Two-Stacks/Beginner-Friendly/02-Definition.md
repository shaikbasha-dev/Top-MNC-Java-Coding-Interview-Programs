# 02 — Definition

## Problem Definition

**Implement a Queue Using Two Stacks** is a data-structure and algorithm problem that tests the ability to manipulate linked-list references or stack/queue behavior correctly.

## Simple Definition

The objective is to perform the requested operation efficiently while preserving the rules of the underlying data structure.

## Important Terms

- **data structures**
- **references/pointers**
- **loops**
- **conditional statements**
- **methods**

## Beginner-Friendly Meaning

Do not memorize pointer movement or stack operations. Understand what each variable represents and why every movement or operation is safe.
