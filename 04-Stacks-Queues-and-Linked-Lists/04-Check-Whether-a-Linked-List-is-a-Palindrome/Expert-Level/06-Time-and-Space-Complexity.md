# 06 — Time and Space Complexity

## Time Complexity

**O(n)**

## Space Complexity

**O(n) beginner; O(1) auxiliary in optimized version**

## How to Explain It

1. Count complete traversals.
2. Count stack/queue operations.
3. Count additional collections.
4. Count recursion or temporary storage if present.
5. State whether the space is auxiliary space.

## Interview Answer

Always provide both time and auxiliary space complexity and explain which operation dominates the result.
