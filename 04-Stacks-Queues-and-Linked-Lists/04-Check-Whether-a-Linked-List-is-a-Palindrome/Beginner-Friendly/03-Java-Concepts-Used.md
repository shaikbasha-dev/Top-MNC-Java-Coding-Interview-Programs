# 03 — Java Concepts Used

## Concepts List

1. Singly linked list
2. Node class
3. ArrayList
4. Two-pointer comparison
5. Boolean result

## Expanded Explanation

### Singly linked list

A singly linked list contains nodes connected through next references.

**General Example:**
```java
10 -> 20 -> 30 -> null
```

### Node class

A Node stores data and a reference to the next node.

**General Example:**
```java
class Node { int data; Node next; }
```

### ArrayList

A resizable list used to store values.

**General Example:**
```java
ArrayList<Integer> values = new ArrayList<>();
```

### Two-pointer comparison

Two indexes or references move toward each other or through the structure.

**General Example:**
```java
left++; right--;
```

### Boolean result

Represents true or false.

**General Example:**
```java
boolean found = true;
```
