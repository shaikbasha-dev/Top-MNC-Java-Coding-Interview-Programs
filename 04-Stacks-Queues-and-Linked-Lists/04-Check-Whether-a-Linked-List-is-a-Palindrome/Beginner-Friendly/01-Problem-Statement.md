# 01 — Problem Statement

## Complete Question

Write a Java program to **check whether a linked list is a palindrome**.

The solution must correctly process the given structure, maintain the required condition after every important operation, handle boundary cases, and produce the expected result.

### Sample Input

```text
[1, 2, 2, 1]
```

### Expected Output

```text
Palindrome = true
```

## Step-by-Step Understanding

1. Read and understand the input structure.
2. Identify exactly what the problem asks.
3. Select the appropriate data structure or pointer technique.
4. Process the structure while maintaining the required invariant.
5. Handle empty, single-element and boundary cases where applicable.
6. Produce the final result.
