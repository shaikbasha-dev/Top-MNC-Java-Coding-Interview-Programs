# 13 — Why Asked in MNC Interviews

## Why Interviewers Ask This Problem

**Remove the Nth Node from the End** tests practical knowledge of data structures and algorithmic thinking.

## Skills Evaluated

1. Understanding of the data structure.
2. Correct reference or pointer manipulation.
3. Correct stack/queue behavior where applicable.
4. Boundary-condition handling.
5. Algorithm selection.
6. Time and space complexity.
7. Ability to explain code.
8. Ability to optimize a straightforward solution.

## Common Follow-Ups

- What happens for an empty structure?
- What happens for one element?
- Can the extra memory be reduced?
- Why does this pointer move safely?
- What is the worst-case complexity?
- Can you solve it in one traversal?
