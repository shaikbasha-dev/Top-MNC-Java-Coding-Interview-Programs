# 03 — Java Concepts Used

## Concepts List

1. Stack
2. Queue
3. FIFO
4. LIFO
5. Queue operations
6. Classes and objects

## Expanded Explanation

### Stack

A LIFO data structure.

**General Example:**
```java
stack.push(10); stack.pop();
```

### Queue

A FIFO data structure.

**General Example:**
```java
queue.offer(10); queue.poll();
```

### FIFO

First In, First Out.

**General Example:**
```java
10 enters before 20, so 10 leaves first.
```

### LIFO

Last In, First Out.

**General Example:**
```java
20 enters last, so 20 leaves first.
```

### Queue operations

Insertion and removal operations used by a queue.

**General Example:**
```java
offer(), poll()
```

### Classes and objects

A class defines a type and an object is an instance of it.

**General Example:**
```java
MyStack stack = new MyStack();
```
