# 01 — Expert Problem Approach

## Expert Strategy

Solve **Climbing Stairs** by identifying the minimum sufficient DP state and avoiding unnecessary recomputation.

1. Define the state precisely.
2. Establish base cases.
3. Derive the recurrence.
4. Determine a valid evaluation order.
5. Reuse stored subproblem results.
6. Identify opportunities for space optimization.
7. Analyze state count and transition cost.
