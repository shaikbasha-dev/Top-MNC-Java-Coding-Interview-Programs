# 13 — Why Asked in MNC Interviews

## Why Interviewers Ask This Problem

**House Robber** tests whether a candidate can recognize a problem where previously calculated subproblem results can be reused.

## Skills Evaluated

1. Identifying overlapping subproblems.
2. Identifying optimal substructure.
3. Defining a correct DP state.
4. Finding the state transition.
5. Correct initialization.
6. Bottom-up table construction.
7. Complexity analysis.
8. Boundary-condition handling.
9. Comparing alternative approaches.
10. Explaining the solution clearly.

## Common Follow-Ups

- Can you solve it using recursion?
- Why is recursion slower?
- What is memoization?
- What is tabulation?
- Can space be optimized?
- What does `dp[i]` represent?
- What is the recurrence relation?
