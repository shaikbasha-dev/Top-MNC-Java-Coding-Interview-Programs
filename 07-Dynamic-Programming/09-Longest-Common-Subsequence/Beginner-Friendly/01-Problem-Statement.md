# 01 — Problem Statement

## Complete Question

Write a Java program to solve the **Longest Common Subsequence** problem using Dynamic Programming.

The program must identify smaller subproblems, define the DP state, initialize base states, calculate transitions from previously solved states, and return the required final answer.

### Sample Input

```text
first = "abcde", second = "ace"
```

### Expected Output

```text
LCS length = 3
```

## Step-by-Step Understanding

1. Understand exactly what the problem asks.
2. Identify smaller subproblems.
3. Define what each DP state represents.
4. Identify the base cases.
5. Derive the state transition.
6. Fill the DP states in the correct order.
7. Read the final answer from the required state.
8. Analyze time and space complexity.
