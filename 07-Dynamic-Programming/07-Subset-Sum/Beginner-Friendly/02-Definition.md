# 02 — Definition

## Problem Definition

**Subset Sum** is a Dynamic Programming problem where the required answer is built from smaller subproblems whose results can be stored and reused.

## Simple Definition

Dynamic Programming is useful when a problem has **overlapping subproblems** and **optimal substructure**. Instead of solving the same smaller problem repeatedly, we calculate it once and store its result.

## Important Terms

- **Dynamic programming**
- **Boolean DP**
- **Include/exclude choice**
- **Two-dimensional array**
- **State transition**

## Beginner-Friendly Meaning

Think of DP as writing down answers to smaller questions first. When a larger question needs one of those answers, the stored result is reused instead of calculating it again.
