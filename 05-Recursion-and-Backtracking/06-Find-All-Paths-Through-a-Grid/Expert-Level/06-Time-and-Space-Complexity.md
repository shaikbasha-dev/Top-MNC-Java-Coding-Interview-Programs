# 06 — Time and Space Complexity

## Time Complexity

**O(number of valid paths × path length)**

## Space Complexity

**O(rows + cols) recursion depth**

## What Determines the Complexity?

1. Number of recursive branches.
2. Number of candidate choices at each level.
3. Maximum recursion depth.
4. Cost of validation at each choice.
5. Cost of producing the output.

## Interview Answer

For recursive problems, explain both the branching factor and recursion depth. If the algorithm generates every valid answer, include output-generation cost in the discussion.
