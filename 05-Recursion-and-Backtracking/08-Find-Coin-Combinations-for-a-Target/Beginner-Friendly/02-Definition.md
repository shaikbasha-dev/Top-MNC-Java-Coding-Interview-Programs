# 02 — Definition

## Problem Definition

**Find coin combinations for a target** is a recursion/backtracking problem in which a large problem is divided into smaller choices and the program systematically explores valid possibilities.

## Simple Definition

Recursion solves a problem by calling the same method on a smaller input. Backtracking extends this idea by making a choice, exploring it, and undoing that choice before trying another option.

## Important Terms

- **recursion**
- **backtracking**
- **arrays**
- **ArrayList**
- **target reduction**

## Beginner-Friendly Meaning

Think of recursion as moving deeper into a decision tree. Think of backtracking as returning to the previous decision point and choosing a different branch.
