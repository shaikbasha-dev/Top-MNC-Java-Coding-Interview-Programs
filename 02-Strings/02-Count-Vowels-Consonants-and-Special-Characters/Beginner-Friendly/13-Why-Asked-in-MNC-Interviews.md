# Why Asked in MNC Interviews — Count Vowels, Consonants and Special Characters

## Why This Problem Is Important

String problems are common in Java interviews because they test careful character-level reasoning, use of Java String APIs, data structures, loops, conditions, and complexity analysis.

## What the Interviewer Is Testing

1. Problem understanding.
2. String traversal.
3. Character comparison or counting.
4. Appropriate Java APIs.
5. Data-structure selection where required.
6. Edge-case handling.
7. Time and space complexity.
8. Ability to explain the solution clearly.
9. Ability to improve a brute-force solution.

## What Makes a Strong Interview Answer?

A strong candidate explains the approach before coding, uses meaningful variable names, handles important edge cases, and states the complexity.

## Common Follow-Up

The interviewer may ask you to reduce nested loops, avoid unnecessary String creation, replace a data structure, or explain how the solution behaves for empty or very large input.
