# Expert Problem Approach — Find the First Non-Repeating Character

## Problem Interpretation

Find the first character in a string that occurs exactly once.

## Key Observation

The expert approach focuses on avoiding unnecessary repeated work. Instead of repeatedly rebuilding the same information, maintain the useful state while traversing the input.

## Expert Strategy

1. Identify the exact property that determines the answer.
2. Choose the smallest suitable data structure.
3. Traverse the input in the direction that makes the required information available.
4. Maintain the important state incrementally.
5. Avoid unnecessary temporary String objects where practical.
6. Handle edge cases explicitly.
7. State the complexity before presenting the code.

## Interview Perspective

The optimized solution should be explained as an improvement over the beginner solution, not as unexplained short code.
