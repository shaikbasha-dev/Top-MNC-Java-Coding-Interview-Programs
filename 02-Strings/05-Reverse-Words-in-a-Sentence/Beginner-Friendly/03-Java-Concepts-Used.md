## Detailed Explanation

### Class

A class is a blueprint/container that groups Java data and behavior.

**General example:**

```java
class Demo { }
```

### main() method

The main method is the standard entry point of a standalone Java application.

**General example:**

```java
public static void main(String[] args) { }
```

### String

String represents a sequence of characters.

**General example:**

```java
String name = "Java";
```

### Variable

A variable is a named location used to store a value.

**General example:**

```java
int count = 10;
```

### for loop

A for loop repeats a block for a controlled number of iterations.

**General example:**

```java
for (int i = 0; i < 5; i++) { }
```

### if statement

An if statement executes code when a condition is true.

**General example:**

```java
if (age >= 18) { }
```

### Comparison operators

Comparison operators compare values and produce true or false.

**General example:**

```java
if (a == b) { }
```

### Assignment operator

The assignment operator stores a value in a variable.

**General example:**

```java
count = 20;
```

### System.out.print()/println()

These methods display program results on the console.

**General example:**

```java
System.out.println("Result");
```

### String split

split divides a string into parts using a delimiter or regular expression.

**General example:**

```java
String[] words = text.split(" ");
```

### String array

A String array stores multiple String values.

**General example:**

```java
String[] words = {"a", "b"};
```
