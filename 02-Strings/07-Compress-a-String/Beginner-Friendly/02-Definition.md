# Definition — Compress a String

## Technical Definition

Compress consecutive repeated characters by writing each character followed by its count.

## Simple Definition

This is a string-processing problem in which the program examines characters or words and applies a specific rule to produce the requested result.

## Beginner-Friendly Explanation

A string is a sequence of characters. The program can inspect a string character by character, compare characters, count them, rearrange them, or build another string depending on the question.

## Important Terminology

- **String:** A sequence of characters.
- **Character:** One individual symbol in a string.
- **Index:** The position of a character, beginning at zero in Java.
- **Frequency:** The number of occurrences of a character.
- **Substring:** A contiguous part of a string.
- **Prefix:** Characters occurring at the beginning of a string.
- **Palindrome:** A sequence that reads the same forward and backward.
- **Anagram:** Two strings containing the same character frequencies in a different or same order.

Only the terms relevant to the current problem need to be applied.
