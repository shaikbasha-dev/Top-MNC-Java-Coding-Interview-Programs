# Time and Space Complexity — Check Whether Brackets Are Balanced

## Beginner-Friendly Approach

**Time Complexity:** `O(n)`

The complexity follows the number of character comparisons, scans, or combinations performed by the beginner implementation.

## Expert-Level Approach

**Time Complexity:** `O(n)`

The expert implementation reduces repeated work where possible or uses a more appropriate data structure.

## Space Complexity

The exact auxiliary space depends on the data structure used. Fixed-size character tables can be O(1), while maps, lists, recursion stacks or generated combinations can grow with the input.

## Interview Explanation

Do not only state Big-O. Explain what causes the complexity and which part of the code dominates the running time.
