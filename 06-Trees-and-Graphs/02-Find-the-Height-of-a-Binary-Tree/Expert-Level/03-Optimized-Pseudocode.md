# 03 — Pseudocode

```text
START
    Build or read the tree/graph
    Initialize required pointers, queue, recursion state or visited array

    IF a base/boundary condition is reached
        return the appropriate result
    END IF

    Process the current node/vertex
    Explore the required child/neighbor nodes
    Maintain visited or parent information when required
    Combine the results

    DISPLAY final result
END
```
