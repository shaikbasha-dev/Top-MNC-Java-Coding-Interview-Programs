# 01 — Expert Problem Approach

## Expert Strategy

Solve **Find the height of a binary tree** by maintaining the smallest state required by the tree or graph invariant.

1. Identify the exact traversal/search property.
2. Define the base or termination condition.
3. Process each node/vertex once whenever possible.
4. Combine recursive results efficiently.
5. Use BFS/DFS state correctly.
6. Avoid repeated traversal where a single pass can calculate the answer.
7. State time and auxiliary space complexity.
