# 01 — Problem Statement

## Complete Question

Write a Java program to **Inorder, preorder and postorder traversal**.

The program must correctly build or process the required tree or graph, apply the appropriate traversal/search technique, handle boundary cases, and produce the required result.

### Sample Input

```text
Tree: 1 with children 2,3; node 2 has children 4,5
```

### Expected Output

```text
Inorder: 4 2 5 1 3
Preorder: 1 2 4 5 3
Postorder: 4 5 2 3 1
```

## Step-by-Step Understanding

1. Understand the tree or graph structure.
2. Identify the required operation.
3. Choose recursion, queue-based traversal, DFS or BST property as appropriate.
4. Define the stopping condition.
5. Process every required node or vertex.
6. Handle null, visited and boundary cases.
7. Produce the final result.
