# 02 — Definition

## Problem Definition

**Perform Breadth-First Search (BFS) and Depth-First Search (DFS)** is a tree/graph data-structure problem that tests the ability to navigate hierarchical or connected data correctly.

## Simple Definition

The objective is to process nodes or vertices according to the rules of the selected tree or graph algorithm and return the required result.

## Important Terms

- **Graph**
- **Adjacency list**
- **BFS**
- **DFS**
- **Queue**
- **Visited array**

## Beginner-Friendly Meaning

A tree is hierarchical data. A graph is connected data. The main skill is knowing how to visit the right nodes in the right order without processing the same vertex incorrectly.
