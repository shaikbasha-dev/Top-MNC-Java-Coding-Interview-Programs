# 03 — Java Concepts Used

## Concepts List

1. Arrays
2. Sorting
3. Min-heap
4. PriorityQueue
5. Loops
6. Generics

## Expanded Explanation

### Arrays

An array stores multiple values of the same type using indexes.

**General Example:**
```java
int[] a = {3, 1, 2};
```

### Sorting

Sorting arranges values in ascending or another chosen order.

**General Example:**
```java
Arrays.sort(a);
```

### Min-heap

A min-heap keeps the smallest element at its root.

**General Example:**
```java
PriorityQueue<Integer> heap = new PriorityQueue<>();
```

### PriorityQueue

PriorityQueue provides heap-based priority ordering.

**General Example:**
```java
heap.offer(5);
```

### Loops

Loops repeat processing for multiple values.

**General Example:**
```java
for (int i = 0; i < a.length; i++) { }
```

### Generics

Generics provide compile-time type safety for collections.

**General Example:**
```java
PriorityQueue<Integer>
```
