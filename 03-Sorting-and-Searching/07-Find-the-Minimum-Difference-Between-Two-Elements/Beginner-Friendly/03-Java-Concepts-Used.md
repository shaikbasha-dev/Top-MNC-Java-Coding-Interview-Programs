# 03 — Java Concepts Used

## Concepts List

1. Arrays
2. Sorting
3. Absolute value
4. Adjacent comparison
5. Loops

## Expanded Explanation

### Arrays

An array stores multiple values of the same type using indexes.

**General Example:**
```java
int[] a = {3, 1, 2};
```

### Sorting

Sorting arranges values in ascending or another chosen order.

**General Example:**
```java
Arrays.sort(a);
```

### Absolute value

Absolute value represents a magnitude without a negative sign.

**General Example:**
```java
Math.abs(-5) == 5
```

### Adjacent comparison

After sorting, nearby values can be compared to find the smallest difference.

**General Example:**
```java
a[i] - a[i-1]
```

### Loops

Loops repeat processing for multiple values.

**General Example:**
```java
for (int i = 0; i < a.length; i++) { }
```
