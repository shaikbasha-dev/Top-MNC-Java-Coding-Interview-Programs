# 08 — Pseudocode

```text
START
    Set low, middle and high pointers.
    If middle is 0, swap with low and advance low and middle.
    If middle is 1, advance middle.
    If middle is 2, swap with high and decrease high without advancing middle.
    Stop when middle passes high.
    DISPLAY result
END
```

## Purpose

The pseudocode describes the algorithm without Java syntax. It should be understandable even before reading the implementation.
