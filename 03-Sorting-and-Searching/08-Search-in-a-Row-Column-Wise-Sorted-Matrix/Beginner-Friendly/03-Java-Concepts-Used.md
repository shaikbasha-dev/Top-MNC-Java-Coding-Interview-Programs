## Expanded Explanation

### 2D arrays

A two-dimensional array stores values in rows and columns.

**General Example:**
```java
int[][] matrix = {{1,2},{3,4}};
```

### Matrix traversal

Matrix traversal visits cells using row and column indexes.

**General Example:**
```java
matrix[row][column]
```

### Two-directional elimination

Each comparison eliminates a complete row or column from consideration.

**General Example:**
```java
move left or move down
```

### while loop

A while loop repeats while its condition remains true.

**General Example:**
```java
while (low <= high) { }
```
