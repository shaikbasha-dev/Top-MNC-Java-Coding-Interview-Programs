# 13 — Why This Problem Is Asked in MNC Interviews

## Why Interviewers Ask This Problem

**Search in a Row/Column-Wise Sorted Matrix** tests whether a candidate can convert a problem statement into an efficient algorithm rather than relying only on Java syntax.

## Skills Being Evaluated

1. Problem-solving ability.
2. Data-structure selection.
3. Algorithm selection.
4. Boundary-condition handling.
5. Ability to reason about sorted data.
6. Time and space complexity.
7. Code readability.
8. Ability to explain the solution and improve it.

## What an Interviewer May Do

The interviewer may first ask for a straightforward solution and then ask:

- Can you optimize it?
- Can you reduce the number of comparisons?
- What happens with duplicate values?
- What happens with an empty or single-element input?
- What is the worst-case complexity?
- Can you solve it without using an extra array or by using a different data structure?

## Strong Interview Approach

Start by explaining the observation, then the algorithm, then write the code, dry-run one example, and finally state the complexity.
