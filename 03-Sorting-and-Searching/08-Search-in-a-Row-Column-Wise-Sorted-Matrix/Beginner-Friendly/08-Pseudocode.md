# 08 — Pseudocode

```text
START
    Start at row 0 and the last column.
    If current value equals target, return its position.
    If current value is greater than target, move left.
    If current value is smaller than target, move down.
    Stop when row or column becomes invalid.
    DISPLAY result
END
```

## Purpose

The pseudocode describes the algorithm without Java syntax. It should be understandable even before reading the implementation.
