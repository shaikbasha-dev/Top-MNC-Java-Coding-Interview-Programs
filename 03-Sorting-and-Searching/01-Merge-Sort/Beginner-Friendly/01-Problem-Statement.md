# 01 — Problem Statement

## Complete Question

Merge Sort is a divide-and-conquer sorting algorithm that repeatedly divides an array into smaller halves, sorts the halves, and merges the sorted halves.

### Given Input

```text
[38, 27, 43, 3, 9, 82, 10]
```

### Required Output

```text
[3, 9, 10, 27, 38, 43, 82]
```

## Question in Interview Form

Write a Java program to solve the problem above and produce the required result.

## What You Must Determine

1. Understand the input structure.
2. Identify the mathematical or algorithmic property that makes the solution efficient.
3. Process the input according to that property.
4. Produce the correct result.
5. Explain the time and space complexity.

## Important Conditions

- Preserve the assumptions stated by the problem, such as sorted input where required.
- Handle boundary cases carefully.
- Do not use an unnecessarily expensive approach when an efficient approach is expected.
