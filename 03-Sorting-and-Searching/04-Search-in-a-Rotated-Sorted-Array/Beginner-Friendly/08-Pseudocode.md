# 08 — Pseudocode

```text
START
    Find the middle index.
    If middle equals target, return it.
    Determine whether the left half is sorted.
    If target lies in the sorted half, search there; otherwise search the other half.
    Repeat until the range is empty.
    DISPLAY result
END
```

## Purpose

The pseudocode describes the algorithm without Java syntax. It should be understandable even before reading the implementation.
