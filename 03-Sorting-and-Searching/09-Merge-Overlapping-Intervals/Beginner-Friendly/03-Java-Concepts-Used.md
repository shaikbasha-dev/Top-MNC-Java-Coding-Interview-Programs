**General Example:**

### Intervals

An interval represents a range with a start and end.

**General Example:**
```java
[1, 5]
```

### Sorting by start

Intervals are ordered by their starting value before merging.

**General Example:**
```java
Arrays.sort(intervals, ...);
```

### ArrayList

ArrayList is a resizable ordered collection.

**General Example:**
```java
List<int[]> result = new ArrayList<>();
```
