# 01 — Expert Problem Approach

## Problem

The median is the middle value of an ordered collection, or the average of the two middle values when the total number of elements is even. The expert solution finds it using binary search on the smaller array.

## Expert Observation

The expert solution should exploit the strongest property of the input rather than performing unnecessary work.

## Strategy

1. Identify the mathematical or ordering property.
2. Choose the most suitable algorithm or data structure.
3. Maintain only the state required to make the next decision.
4. Avoid repeated scans where the input structure allows elimination.
5. Handle boundaries explicitly.
6. Prove or explain why each pointer/index movement is safe.
7. State the complexity.

## Interview-Level Thinking

The expert solution is not about writing shorter Java code. It is about demonstrating that the algorithm performs the minimum reasonable amount of work for the stated constraints.
