## Expanded Explanation

### Arrays

An array stores multiple values of the same type using indexes.

**General Example:**
```java
int[] a = {3, 1, 2};
```

### Median

Median is the middle value of ordered data, or the average of two middle values.

**General Example:**
```java
[1,2,3] -> 2
```

### Binary search

Binary search repeatedly halves a sorted search range.

**General Example:**
```java
low=0; high=a.length-1;
```

### Partition

A partition divides the two sorted arrays so every left-side value is <= every right-side value.

**General Example:**
```java
leftA <= rightB && leftB <= rightA
```

### Integer arithmetic

Integer arithmetic is used for indexes and discrete values.

**General Example:**
```java
int middle = low + (high-low)/2;
```

### Double precision

double stores fractional numeric values needed for an even-sized median.

**General Example:**
```java
double median = 2.5;
```
